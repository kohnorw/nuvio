Review & push

This is a clean install. Each selected profile is reset to exactly Cinemeta, OpenSubtitles v3, Xperience, your chosen AIOStreams build and — if Live TV is on — the IPTV addon. Every other addon is removed, and all existing collections are replaced by the bundled Streaming and Genres ones. Run Preview changes first to see what would go.
